# Интеграция с Claude Code

## Установка

1. Скопируйте `templates/field-card.md` и `docs/` в проект:
   ```bash
   cp -r templates/ docs/ ваш_проект/spiral-maturity/
   ```
2. Добавьте в `CLAUDE.md` проекта:
   ```markdown
   ## Spiral Maturity
   При оценке зрелости компании используй методику из `spiral-maturity/docs/methodology-ru.md`.
   Заполняй `templates/field-card.md` на встрече. Уровень — гипотеза, не диагноз.
   ```
3. Запустите Claude Code в папке проекта.

## Использование

```bash
# Оценить компанию
claude "Оцени зрелость компании по Спирали. Факты: сайт, кейсы, позиционирование. Заполни field-card."
```

## Что делает агент

1. Читает `docs/methodology-ru.md` — 7 уровней ценностей.
2. Собирает факты о компании (сайт, кейсы, отзывы, цифры) — **факты до оценки**, стереотип бизнес-модели не вход.
3. Заполняет `templates/field-card.md`: 10 индикаторов по шкале 1–7.
4. Называет доминантный уровень, разброс, главную проблему и один следующий шаг.

## Стоп-правила

- Уровень — гипотеза, не диагноз.
- Стереотип («аутсорсер = часы», «стартап = хаос») — не вход: подменяет реальную компанию догадкой.
- Разброс > 2 баллов между индикаторами = компания неоднородная.
