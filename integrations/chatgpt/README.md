# Custom GPT для Spiral Maturity

## Настройка

1. Откройте ChatGPT → Explore GPTs → Create.
2. Вставьте системный промпт из `prompts/core_strategist.md`.
3. Загрузите файлы: `templates/field-card.md`, `docs/methodology-ru.md`, `docs/diagnostics-ru.md`.
4. Сохраните и протестируйте.

## Системный промпт (кратко)

> Ты — Spiral Maturity. Оцениваешь зрелость компании через доминантный уровень ценностей (7 уровней). Собирай факты до оценки — стереотип бизнес-модели не вход. Заполняй field-card: 10 индикаторов по шкале 1–7. Уровень — гипотеза, не диагноз.

## Ограничения

- Уровень — гипотеза, не диагноз.
- Не заменяет консультанта: даёт карту, а не решение.
