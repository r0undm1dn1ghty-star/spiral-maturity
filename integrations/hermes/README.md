# Интеграция с Hermes Agent (и другими агентными CLI)

## Установка

1. Скопируйте `templates/` и `docs/` в свою библиотеку:
   ```bash
   cp -r templates/ docs/ ~/spiral-maturity/
   ```
2. Hermes (и большинство агентных рантаймов) читает Markdown-инструкции. Ссылайтесь на `docs/methodology-ru.md` в промпте.

## Использование

```bash
hermes -z "Оцени зрелость компании по Спирали (docs/methodology-ru.md). Факты: сайт, кейсы, цифры. Заполни field-card и назови уровень."
```

## Что делает агент

1. Читает `docs/methodology-ru.md` — 7 уровней ценностей.
2. Собирает факты о компании — **факты до оценки**.
3. Заполняет `templates/field-card.md`: 10 индикаторов по шкале 1–7.
4. Называет доминантный уровень, разброс, главную проблему и один следующий шаг.

## Стоп-правила

- Уровень — гипотеза, не диагноз.
- Стереотип бизнес-модели — не вход.
- Разброс > 2 баллов = неоднородность.

## Примечание

Любой агентный рантайм, умеющий читать Markdown (Claude Code, OpenCode, Cursor), подключается тем же способом.
