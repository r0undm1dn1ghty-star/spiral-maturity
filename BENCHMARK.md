# Бенчмарк — Spiral Maturity

Задача: определить ступень агентной зрелости организации по признакам
использования ИИ. Проверено на 4 кейсах.

## Результат

| Метод | Верных ступеней |
|---|---|
| Наивный (всегда «низшая ступень») | 1/4 |
| **Spiral Maturity** | **4/4** |

## Ступени лестницы A0–A4

| Признак | Ступень |
|---|---|
| автономные агенты + оркестрация | A4 |
| агенты встроены в процессы | A3 |
| регламент использования ИИ | A2 |
| ручной режим | A0 |

Инструмент различает отрицание («нет регламентов» ≠ A2) и отсутствие данных
(выводит `null`, а не «уровень 1»).

## Как воспроизвести

```bash
git clone https://github.com/r0undm1dn1ghty-star/spiral-maturity
cd spiral-maturity
echo '{"процессы":"автономные агенты и оркестрация","метрики":"замеряем"}' \
  | python integrations/kit/skillkit.py --json
```
