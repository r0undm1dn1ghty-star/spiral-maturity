# Eval — Spiral Maturity на реальных организациях

Диагностика проверена на **8 реальных организациях** по открытым признакам
использования ИИ. Не тестовые данные — публично известные практики компаний.

## Результаты

| Организация | Ступень | Уровень | Уверенность | Формат внедрения |
|---|---|---|---|---|
| Яндекс | A4 | 7 | high | Автономные агенты + оркестрация |
| Сбер | A3 | 4 | high | Встроенные агенты |
| Т-Банк | A4 | 4 | high | Автономные агенты + оркестрация |
| Ozon | A3 | 4 | high | Встроенные агенты |
| МТС | A3 | 6 | high | Встроенные агенты |
| Магнит | A2 | не наблюдаю | medium | Регламентированное использование |
| Лента | A2 | 3 | high | Регламентированное использование |
| Авито | A3 | 6 | high | Встроенные агенты |

## Что учитывает

| Индикатор | Как учитывается |
|---|---|
| Ступень агентной зрелости A0–A4 | по маркерам использования ИИ: ручной режим → автономные агенты с оркестрацией |
| Уровень ценностей 1–7 | по признакам приоритетов: выживание → контроль → прибыль → клиент → команда → миссия → влияние |
| **Отрицание** | «нет регламентов» не даёт ступень A2, где регламент требуется — отрицание распознаётся в окне перед маркером |
| **Отсутствие данных** | если признаков уровня нет, выводится `null` и «не наблюдаю», а не «уровень 1» |
| Уверенность | из полноты наблюдений: `high` — есть и ступень, и уровень; `low` — нет ни одного |
| Разрыв «зрелость × агенты» | если организация зрелая, а агенты не используются — фиксируется как быстрый выигрыш |
| Формат внедрения | из ступени: ручной режим → регламент → встроенные агенты → оркестрация |

## Проверка

```bash
git clone https://github.com/r0undm1dn1ghty-star/spiral-maturity
cd spiral-maturity
python integrations/kit/skillkit.py --json \
  --input '{"процессы":"автономные агенты и оркестрация","метрики":"замеряем","ценности":"влияние на отрасль"}'
# -> stage A4, level 7, confidence high

python integrations/kit/skillkit.py --json \
  --input '{"процессы":"пробуем ИИ","документы":"нет регламентов"}'
# -> level null ("не наблюдаю"), ступень ниже A2 — отрицание распознано
```
